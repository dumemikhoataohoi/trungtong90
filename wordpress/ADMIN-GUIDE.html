Editing kuritabooth.global without touching code Chỉnh sửa kuritabooth.global mà không cần biết code

This handbook covers everything a content editor needs day to day: editing text and images, reordering page sections, managing the 5 MAX Series products, publishing Case Studies, and switching between English and Vietnamese. Sổ tay này bao gồm mọi thao tác biên tập viên cần làm hàng ngày: sửa văn bản/hình ảnh, sắp xếp lại các section trên trang, quản lý 5 sản phẩm MAX Series, đăng Case Study, và chuyển đổi giữa Tiếng Anh và Tiếng Việt.

00 How the site is organizedCấu trúc của website

The visual design (colors, layout, fonts, animations) is fixed and controlled — you cannot break it by editing content. What you control is text, images, PDFs, and the order/presence of sections. Thiết kế hình ảnh (màu sắc, bố cục, font chữ, hiệu ứng) được cố định và kiểm soát — bạn không thể làm hỏng nó khi chỉnh sửa nội dung. Những gì bạn kiểm soát là văn bản, hình ảnh, PDF, và thứ tự/sự hiện diện của các section.

05 BrochuresBrochure

Brochures → Add New → give it a title → "Select PDF" and choose the file → set the download button text (e.g. "Download Brochure (PDF)") → set a cover thumbnail as Featured Image → Publish. Then go to the relevant MAX product and pick this brochure from its "Brochure PDF" dropdown. Brochures → Add New → đặt tiêu đề → "Select PDF" và chọn file → đặt nội dung nút tải (vd: "Download Brochure (PDF)") → đặt ảnh bìa ở Featured Image → Publish. Sau đó vào sản phẩm MAX tương ứng và chọn brochure này ở dropdown "Brochure PDF".

To replace a PDF later (new revision), edit the same Brochure entry and click "Replace PDF" — the download link and button stay the same, only the file changes. Để thay PDF sau này (phiên bản mới), sửa lại đúng bài Brochure đó và click "Replace PDF" — link và nút tải giữ nguyên, chỉ file thay đổi.

06 Site SettingsCài đặt chung

Left sidebar → Site Settings. These strings repeat on every page, so they live in one place instead of ten: the red top announcement bar, the footer description and legal disclaimer, the "Markets" note, and the contact details shown on the Contact page. Thanh bên trái → Site Settings. Các đoạn văn bản này lặp lại trên mọi trang, nên được đặt ở một nơi duy nhất thay vì mười nơi: thanh thông báo đỏ trên cùng, mô tả footer và disclaimer pháp lý, ghi chú "Markets", và thông tin liên hệ hiển thị trên trang Contact.

07 English + Vietnamese contentNội dung Tiếng Anh + Tiếng Việt

The site uses Polylang (a free plugin) so each page/product/case study has an English version and a linked Vietnamese version at its own URL (/en/... and /vi/...) — not a single page with both languages mixed together. Website dùng Polylang (plugin miễn phí) để mỗi trang/sản phẩm/case study có 1 bản Tiếng Anh và 1 bản Tiếng Việt liên kết với nhau, mỗi bản có URL riêng (/en/... và /vi/...) — không phải 1 trang trộn lẫn cả hai ngôn ngữ.
